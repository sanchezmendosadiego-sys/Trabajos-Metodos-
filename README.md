# Trabajos de Métodos Cuantitativos y Análisis de Datos

Este repositorio contiene scripts en Python y R desarrollados para realizar análisis estadísticos, modelos de regresión lineal múltiple y gestión de bases de datos relacionales directamente desde la terminal de Linux.

**Contenido del Repositorio**
* **`analisis.py` / `analisis.R`**: Scripts para calcular estadísticas descriptivas (media, varianza, desviación estándar) y construir ecuaciones de regresión lineal.
* **`cotizaciones.py`**: Automatización en Python utilizando SQLAlchemy y Pandas para conectar, extraer y analizar precios directamente desde una base de datos PostgreSQL local.
* **`comparar_sexenios.py` / `comparar_sexenios.R`**: Análisis comparativo de indicadores históricos mediante la limpieza y procesamiento de datos en formato CSV.
* **`resultados_prueba.csv`**: Exportación automatizada de los datasets procesados.
* **`evolucion_precios.png`**: Visualización gráfica de los resultados generados por los modelos.

**Tecnologías y Entorno**
* **Lenguajes:** Python (Pandas, Scikit-Learn, SQLAlchemy) y R.
* **Base de Datos:** PostgreSQL.
* **Sistema Operativo:** GNU/Linux Debian (Bash, Nano/Emacs).
